


## 🛒 Superstore Sales Dashboard (Excel)

This project is an interactive **Excel dashboard** that analyzes sales data from a retail superstore. It provides insights into product line performance, city-wise sales, payment preferences, and peak sales hours — all built using pivot tables, charts, and slicers in Excel.

---

### 📊 Key Insights:

* 💰 **Total Sales:** `322,966.75`
* ⏰ **Peak Sales Hour:** 7 PM – 8 PM
* 🥇 **Top Product Line:** Electronic Accessories
* 🏙️ **Cities Analyzed:** Mandalay, Naypyitaw, Yangon
* 🧾 **Popular Payment Methods:** E-Wallet, Cash

---

### 📁 Dataset Overview:

The dataset includes:

* Product Line
* City
* Sales Amount
* Hour of Sale
* Payment Mode
* Invoice ID

---

### 🛠️ Tools & Features Used:

* Microsoft Excel
* Pivot Tables
* Pivot Charts (Bar, Line, Pie)
* Slicers (for dynamic filtering by City and Hour)
* Conditional Formatting
* Dashboard Layout Design (Dark Theme)
